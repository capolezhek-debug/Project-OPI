## Общие требования

- Игра «Крестики‑нолики» для двух игроков, запускается как консольное приложение на C++.  
- Поле 3×3, отображается после каждого хода в удобном для чтения текстовом виде.  


## Функциональные требования

- Игроки ходят по очереди: первый играет крестиками `X`, второй – ноликами `O`.  
- Ввод хода осуществляется с клавиатуры (номер клетки или координаты строки и столбца).  
- Программа проверяет корректность ввода и не даёт походить в уже занятую клетку.  
- После каждого хода выполняется проверка победы по строкам, столбцам и диагоналям.  
- Если один из игроков выстроил три своих символа подряд, программа объявляет победителя и завершает игру.
- При выигрыише либо проигрыше выводить надпись для пользователя с соответствующим цветом (зелёный - победа, красный - проигрыш). 
- Если все клетки заполнены и победителя нет, выводится сообщение о ничьей.
- Добавления цвета к крестикам ноликам (крестики - красные, нолики - синие).
- Обозначение свободных ячеек зелёным цветом, ячеек, выбранных пользователем ошибочно - жёлтым цветом.


## Нефункциональные требования

- Код должен быть разбит минимум на функции: вывод поля, ввод и проверка хода, проверка победы, основной игровой цикл.  
- Исходный код компилируется стандартным компилятором C++ (g++, clang, MSVC) без использования сторонних библиотек, кроме стандартной библиотеки.  
- Все сообщения пользователю должны быть на русском языке и понятны без дополнительных пояснений.  


## Дополнительные (опциональные) требования

- Возможность начать новую игру без перезапуска программы.  
- Подсказка, кто сейчас ходит, и краткая инструкция по вводу в начале игры.
